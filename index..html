¿Qué es el IDH?

El Índice de Desarrollo Humano, del Programa de las Naciones Unidas para el Desarrollo (PNUD), mide en un valor de 0 a 1 las capacidades básicas de las personas. Entre más cerca de 1, mayor desarrollo humano.
